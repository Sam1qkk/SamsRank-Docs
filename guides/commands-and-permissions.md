# Commands & Permissions

### Commands

All commands can be used with the `/samsrank` or `/sr` prefix.

{% hint style="info" %}
#### Skip the Commands

You can perform all these steps visually using the [In-Game Editor](https://kdr-202604-e3dnxpe8.kodari.wiki/guides/ingame-editor). Simply run `/samsrank` to manage your ranks without typing long commands.
{% endhint %}

|       Command      |               Description              |     Permission    |
| :----------------: | :------------------------------------: | :---------------: |
|  /samsrank reload  | Reload config and update resource pack |  samsrank.reload  |
|  /samsrank convert |    Converts PNGs in the ranks folder   |  samsrank.convert |
| /samsrank generate |    Generate a PNG via API instantly    | samsrank.generate |
|   /samsrank list   | Interactive preview of converted ranks |   samsrank.list   |
|  /samsrank effects |    Browse shader-based rank effects    |  samsrank.effects |
|  /samsrank rename  |       Rename a rank and its files      |  samsrank.rename  |
|  /samsrank delete  |        Permanently remove a rank       |  samsrank.delete  |
|  /samsrank cleanup |    Remove orphaned textures/configs    |  samsrank.cleanup |
