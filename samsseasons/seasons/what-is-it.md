# What is It?

## The Four Seasons

What each season looks like and changes, with the default settings. Every number here is a default: change it in the file named in brackets.

Each season has three **phases**: early, mid and late. Many values change from phase to phase, so a season builds up and fades out instead of switching on and off. The first days of a new season blend in from the old one: the land turns patch by patch over the `transition` set in `seasons.yml`.

{% hint style="info" %}
**Growth and chances:** `1.0` = vanilla, `1.4` = 40% faster or more, `0.5` = half, `0` = none.
{% endhint %}
