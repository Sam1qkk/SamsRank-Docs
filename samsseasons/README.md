# Home

## SamsSeasons&#x20;

SamsSeasons brings **Spring, Summer, Autumn and Winter** to your Minecraft server. The land really changes with the seasons: leaves turn gold and fall, snow settles and melts away, cherry blossoms bloom on the oaks, winter nights grow long, and players feel the cold.

{% hint style="success" %}
#### **Works out of the box!**

Drop the jar in, start the server, and the seasons run. No datapack to install, no restart needed for the seasonal colours, and every feature can be tuned or switched off. 🍂
{% endhint %}

***

### Compatibility

{% tabs %}
{% tab title="Software" %}
* **Java:** 21+
* **Server Version:** 1.21+
* **Supported Software:** Paper (and forks like Purpur)
* **Folia:** not supported
{% endtab %}

{% tab title="Integrations" %}
* **PacketEvents** seasonal grass, leaf and water colours (recommended)
* **ItemsAdder / Nexo** automatic resource-pack merging
* **WorldGuard** region flags for temperature, particles, snow, crops and mobs
* **PlaceholderAPI** season, date, weather, festival and temperature placeholders
* **Multiverse** seasons in every world, one shared calendar
* **BlueMap / Dynmap** seasonal snow stays off your web map
* **MySQL** one calendar for a whole network
{% endtab %}
{% endtabs %}
