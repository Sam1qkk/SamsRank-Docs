# Home

## SamsWheel <a href="#samshead" id="samshead"></a>

SamsWheel is a premium Fortune Wheel plugin for Minecraft servers. Unlike chest-menu crates, every wheel is a **real, animated wheel built from display entities that lives in your world** players walk up, right-click, and watch it physically spin to a prize!

{% hint style="success" %}
### **Configure everything in-game**

SamsWheel ships with a full in-game editor. Look around to move the cursor, click to edit, and design an entire wheel rewards, cost, animation, colours and holograms without ever opening a config file!
{% endhint %}

***

### Compatibility

{% tabs %}
{% tab title="Software" %}
* **Java:** 21+
* **Server Version:** 1.21+
* **Supported Software:** Paper (and forks like Purpur)
* **Bedrock players:** via [Geyser](https://github.com/Sam1qkk/SamsWheel/blob/main/docs/guides/bedrock.md)
{% endtab %}

{% tab title="Integrations" %}
* **Geyser / Floodgate** -> Bedrock players see and spin the wheels
* **WorldGuard** -> `samswheel-use` region flag
* **PlaceholderAPI** -> chances, cooldowns, tickets and stats
* **Vault** -> money (economy) cost
* **ItemsAdder / Nexo** -> resource-pack merging and custom reward icons
{% endtab %}
{% endtabs %}
